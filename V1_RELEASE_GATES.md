5. **Approve and publish root website, then exercise the full golden path** with designated non-production identities. Run release regression, operational drill and owner/legal signoff. Mark each gate `PASS` only with recorded evidence for this revision.

## E. Release stop rule

When **all eight gates are `PASS` for the same release candidate**, v1 scope closes. New ideas go to [POST_V1.md](POST_V1.md) and cannot delay launch unless they uncover a security, legal, transaction-integrity or severe usability defect. A local fixture, browser emulation, owner-reported QR scan or public audit site never upgrades an unrelated gate to `PASS`.
