# TEST EVIDENCE

The permanent verification matrix (`T-###`). Older, finer-grained evidence remains in [TEST_EVIDENCE.md](../../TEST_EVIDENCE.md) and
[PRODUCTION_RELEASE_TEST.md](../../PRODUCTION_RELEASE_TEST.md) (both frozen at 2026-09-30); this matrix supersedes them where it is newer.

**Columns.** *Result* = `PASS`, `FAIL`, `PARTIAL`, `NOT RUN`. *Status* = evidence class from the [README vocabulary](README.md#status-vocabulary):
`VERIFIED` (real environment, Tier 1/2), `TESTED` (local/synthetic/fixture), `OWNER-REPORTED` (Tier 3), `PLANNED` (not run). A passing `TESTED` row is **not** proof of
production behavior. Times are UTC. Evidence IDs: [EVIDENCE-INDEX.md](EVIDENCE-INDEX.md).
